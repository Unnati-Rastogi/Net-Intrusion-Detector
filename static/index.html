ML Network Intrusion Detection System

A Random Forest model (trained on NSL-KDD-style data) classifies network-flow records as normal or anomaly, then scores the model's own evidence. Risk scores are model-derived prioritization scores — not attack severity — and priorities order analyst review, nothing more.

Fast batch demonstration

Pulls 10 real rows from the unlabelled test dataset and sends them to POST /predict/batch — the fast path (model scores only, no SHAP).

College minor project - ML core: scikit-learn RandomForest (200 trees); API: FastAPI. Detection, risk, and priority operate on structured network-flow records, not live packet capture. The test dataset is unlabelled, so the demo shows model verdicts rather than accuracy.
